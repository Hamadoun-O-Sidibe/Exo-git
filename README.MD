# Git & GitHub

## 📚 À propos

Ce projet est un exercice pratique réalisé dans le cadre de ma formation en développement full-stack.

L'objectif est d'apprendre à utiliser **Git** et **GitHub** pour gérer, versionner et partager nos projets de développement.

## 🎯 Objectifs

- Comprendre les bases de Git.
- Créer et gérer un dépôt GitHub.
- Enregistrer les modifications avec des commits.
- Envoyer et récupérer du code avec `push` et `pull`.
- Travailler avec des branches.
- Comprendre le fonctionnement de GitHub dans un projet collaboratif.

## 🛠️ Technologies utilisées

- Git
- GitHub
- Git Bash
- Visual Studio Code

## 🚀 Commandes principales

```bash
# Initialiser un dépôt
git init

# Vérifier l'état du projet
git status

# Ajouter les fichiers
git add .

# Enregistrer les modifications
git commit -m "Initial commit"

# Relier le dépôt local à GitHub
git remote add origin URL_DU_DEPOT

# Envoyer le code sur GitHub
git push -u origin main
